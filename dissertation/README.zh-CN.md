# 最终论文数值代码复现

这里是当前论文使用的数值资源。根目录仍保留v0.1.0的光滑一维示例；本目录增加幂函数、一维四范数、二维扩展、求积和采样诊断。

## 运行

先安装Python 3.12，在仓库根目录用CMD执行：

```cmd
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r dissertation\requirements-lock.txt
.venv\Scripts\python.exe dissertation\reproduce.py
```

此命令复用保存数据，重新计算独立检查并生成8张表、3幅图，不重新求解FEM。完整重新计算用：

```cmd
.venv\Scripts\python.exe dissertation\reproduce.py --recompute
```

成功应出现`REPRODUCTION PASSED`。每次运行写入独立的`dissertation/runs/`子目录，已有目录不会被覆盖。Linux命令、详细文件和误差容差见[英文说明](README.md)。

## 复用了什么

- 原有最终论文求解器：一维精确原函数载荷、高精度检查、二维P1三角网格与degree 2–5求积。
- 保存的14个结果文件：CSV、规则系数、8组二维解向量及历史验证记录。
- 144项结果审计、8项采样阶区间检查、15项积分极限检查。
- 最新表格整理与收敛图脚本，包括四范数理论/实测阶对照和参考斜率。
- 曲线与误差分布图从原图表脚本提取，未重新实现求解算法。

为脱离私人工作目录运行，只调整包装和文件路径，并删除一项需要旧私人结果文件的历史比对。因此完整独立求解有150项检查，发布的原参考记录仍有151项；不是少算了一组FEM实验。全部审计仍运行。

一维是主线，二维是扩展。二维最大误差为采样值，约1.83的观测阶没有被宣称为理论极限；阶数与求积点数也明确区分。论文正文、讲义、录音、邮件、学号、本机路径和登录凭据没有发布。
